# 2_TERMO

Repositório acadêmico contendo atividades, exercícios, projetos e materiais de estudo desenvolvidos ao longo do segundo termo.

## Objetivo

Este repositório reúne conteúdos de diferentes áreas do curso, como:

- Backend e JavaScript
- Banco de Dados e SQL
- Front-end com HTML/CSS
- Organização de arquivos e projetos
- Exercícios e atividades práticas

## Principais áreas

### BACKEND
Diretório com scripts e exercícios em JavaScript, incluindo manipulação de dados, lógica de programação, leitura de arquivos e atividades práticas relacionadas a backend.

### BCD
Contém atividades de banco de dados, incluindo SQL, modelagem de dados, relacionamento entre tabelas e projetos práticos.

### LIMA
Repositório dedicado a atividades de front-end, com páginas em HTML, CSS e exercícios de layout.

### ORGANIZAR
Área para organização do repositório, documentação e arquivos auxiliares.

### PROJETOS
Espaço para materiais extras e projetos em desenvolvimento.

## Tecnologias e ferramentas

- JavaScript
- Node.js
- HTML
- CSS
- SQL
- Git e GitHub

## Como usar

1. Clone o repositório:

```bash
git clone <url-do-repositorio>
```

2. Acesse a pasta do projeto:

```bash
cd 2_TERMO
```

3. Navegue pelos diretórios conforme a área de estudo desejada.

4. Execute os arquivos de acordo com a linguagem e a atividade correspondente.
